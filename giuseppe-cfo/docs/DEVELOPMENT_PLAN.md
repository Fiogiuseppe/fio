# Development plan

## Current focus

Stabilise the local accounting/administrative MVP before any optional additions.

## Phase 1 (current)

- Migration-safe startup with Alembic.
- Complete core page flows for clients, quotes, invoices, expenses, documents, settings, reports, backups, and audit logs.
- Strengthen tests around numbering, lifecycle states, exports, and restore safety.

## Phase 2

- Add controlled correction workflow for sent invoices.
- Improve report depth and dashboard trend views.
- Expand form-level validation and UX confirmations.
- Add optional local PDF generation for quotes/invoices.

## Phase 3

- Extend integration tests for full end-to-end page workflows.
- Improve audit analytics and change history views.
- Add optional temporary demo database mode for onboarding/training.
